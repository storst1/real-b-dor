# История матчей Transfermarkt: доступные данные

Проверено 25 ноября 2026 года на официальном JSON API через тот же `transfermarkt-api==5.0.0`, который используется в соседнем проекте. Индивидуальные веса матчей пока не применяются.

## Что уже сохраняется

`player/{id}/performance-game` возвращает историю клубных матчей и матчей сборных, включая встречи, в которых игрок остался в запасе или отсутствовал. Для сезонных количественных показателей и `competitions[].matches` используются только записи с `participationState="played"`. Стадия и результат команды определяются по всем выбранным записям, поэтому пропуск финала игроком не меняет результат его команды.

Каждая сохранённая запись сыгранного матча содержит:

| Поля | Источник и смысл |
| --- | --- |
| `id`, `date` | ID Transfermarkt и время начала в UTC |
| `team_id`, `team`, `opponent_id`, `opponent` | Команда и соперник; названия загружаются существующим пакетным запросом клубов |
| `competition_id`, `competition`, `competition_type_id`, `season_id` | Турнир, его тип и сезон провайдера |
| `stage_code` | Код стадии: например, `FF`, `HF`, `HFH`, `HFR` |
| `venue`, `is_home` | Указанные провайдером домашнее/гостевое/нейтральное поле; для нейтрального или неизвестного поля `is_home=null` |
| `goals_for`, `goals_against`, `score_includes_shootout` | Итоговый счёт со стороны команды игрока; при серии пенальти суммы включают её голы |
| `minutes`, `goals`, `assists` | Фактические показатели игрока из записи матча; неизвестное значение остаётся `null` |
| `position_id`, `started` | Позиция в этом матче и выход в стартовом составе; неизвестное значение остаётся `null` |
| `game_state` | Состояние матча, включая `extra_time` и `penalty_shootout` |

Сезонные матчи, голы, передачи и минуты считаются по прежним правилам. Добавление деталей не меняет эти суммы. В `stage_history` сохраняются реальные коды всех достигнутых стадий, включая полуфинал перед матчем за третье место.

## Что потребуется для будущих весов матчей

Для веса по турниру, стадии, сопернику, дате, месту проведения, позиции или минутам уже достаточно сохранённых полей Transfermarkt и оценок отдельных матчей FotMob. Перед расчётом потребуется надёжно сопоставить встречи двух источников: их ID различаются. Использовать только совпадение ID нельзя.

В полном ответе `performance-game` также встречаются замены, карточки, передачи, удары и другие индивидуальные показатели; историческое покрытие неодинаково. Эти дополнительные показатели пока не включены в локальную схему матча.

Историческая сила соперника, его рейтинг перед матчем и однозначно определённое положение в таблице **до** игры не обеспечиваются текущей схемой. Поле `clubRank` в исходном ответе не имеет подтверждённой семантики «перед матчем» и не должно автоматически использоваться для такого веса. Исторические составы и их стоимость могут потребовать дополнительных запросов `game/{id}` и отдельной проверки покрытия. Для раздельного учёта счёта за игровое время и серии пенальти потребуются дополнительные данные событий: сохранённый итоговый счёт может включать оба компонента.

Ранее добавленные игроки получают новые подробности после обновления: старые записи с одними `id/date` не содержат достаточно данных для восстановления соперника, позиции и минут без повторной загрузки.

## Завершение чемпионата и классификация бонусов

У ответа таблицы `competition/{id}/table?season=...` поле `meta.seasonId` обозначает текущий сезон даже при запросе исторической таблицы. Его нельзя использовать для проверки окончания выбранного сезона.

Для обычного чемпионата с одной общей таблицей адаптер проверяет число туров именно выбранного сезона: `competition/{id}/season` → `seasons[].gameDays`. `competition_complete=true` выставляется, когда у всех клубов столько же сыгранных матчей, у всех явно отсутствует текущая игра и таблица имеет уникальные общие места. Если сыграно меньше, возвращается `false`. Для сложных групповых форматов, смешанных сезонов или недостаточных данных возвращается `null`; текущий лидер не объявляется чемпионом по календарной дате.

Проверенные примеры: Бундеслига 2023/24 — 34 тура, все клубы сыграли 34; текущая Бундеслига 2026/27 — 34 тура, на момент проверки сыграно 10. АПЛ и Ла Лига 2023/24 имеют по 38 туров в записи соответствующего сезона.

Проверенные идентификаторы турниров для бонусов: `CL` — основная Лига чемпионов УЕФА, `FIWC` — чемпионат мира, `EURO` — Евро, `COPA` — Копа Америка, `CA16` — Копа Америка Centenario 2016. Квалификация Лиги чемпионов имеет отдельный ID `CLQ`.

Типы Transfermarkt: `8` — национальный кубок, `14` — кубок лиги, `9` — национальный суперкубок, `15` — юношеский национальный кубок, `23` — юношеский национальный суперкубок. Для согласованного бонуса за взрослые кубки подходят типы `8` и `14`; суперкубки и юношеские турниры в него не входят.
