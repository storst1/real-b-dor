# История матчей для будущих весов

Проверено на реальных данных Harry Kane за 2023/24, 25 ноября 2026 года.

**Индивидуальные веса матчей технически доступны. Ограничиваться весами турниров не требуется.** Приложение уже загружало списки матчей, из которых рассчитывало средние. Раньше сохранённый список обрезался до ID и даты; теперь в нём сохраняются поля, нужные для следующего шага.

## Что получаем

| Данные | FotMob | Transfermarkt |
| --- | --- | --- |
| ID матча, дата | Есть | Есть |
| Турнир, команда, соперник | Есть | Есть |
| Индивидуальная оценка за матч | Есть, если опубликована | Нет |
| Минуты, голы, передачи | Есть | Есть |
| Стадия | Есть не у всех матчей | Есть коды стадий |
| Номинальная сторона хозяева/гости | Есть | Есть |
| Счёт | Есть, без явного результата серии пенальти | Есть итоговые значения, в сериях могут включать пенальти |
| Готовый вес или «важность» матча | Нет | Нет |

FotMob на этом примере потребовал **6 запросов**: поиск, профиль и 4 страницы истории по 20 строк. Получено **59 сыгранных матчей и 59 оценок** за выбранный период. Прямой проверочный запрос занял около 1,3 секунды; приложение дополнительно выдерживает паузы между запросами. Для имеющихся полей отдельные карточки всех 59 матчей не нужны.

Стадия в истории FotMob была заполнена у **11 из 59** встреч; у остальных она отсутствовала. Опубликованные оценки в этом ответе имеют точность в один знак после запятой, поэтому их среднее может немного отличаться от сезонной карточки FotMob.

## Какие веса можно будет задавать

Без дополнительных сетевых запросов можно назначать вес конкретному матчу по ID либо применять правила по турниру, дате, сопернику, минутам и доступной стадии. После определения формулы пересчёт можно выполнять локально на сохранённой истории.

Структура расчёта по утверждённым [правилам весов](season-points.md):

`ID матча → оценка FotMob → основной вес → дополнительные правила → вклад во взвешенную оценку`.

Правила вроде «вес финала», «вес дерби», «вес матча против лидера» потребуют разных данных: стадии часто доступны сразу, список дерби придётся определить, а положение соперника именно перед матчем обычно потребует отдельной истории таблиц. Номинальные хозяева в финале не доказывают игру на домашнем стадионе.

## Хранение и ограничения

- В данных каждого турнира `matches` содержит записи Transfermarkt, а `fotmob_matches` — записи FotMob с индивидуальными оценками. Исходные ответы адаптеров также сохраняются в SQLite.
- При достаточном контексте вес вычисляется напрямую по FotMob. Сопоставление конкретного матча с Transfermarkt используется только для недостающих сведений, например стадии. У источников разные ID; сравнение по одному числу ID невозможно.
- Матчи без опубликованной оценки остаются без неё и не входят в числитель или знаменатель взвешенной оценки.
- Старые сохранения с короткими списками нужно обновить из источников, чтобы получить подробные поля. Данные не выдумываются при чтении старой базы.
- Веса назначаются по согласованным [правилам расчёта](season-points.md). История источников сохраняется отдельно от рассчитанных весов.

Подробные проверочные отчёты: [FotMob](match-history-fotmob.md), [Transfermarkt](match-history-transfermarkt.md). Правила очков: [Баллы за сезон](season-points.md).
