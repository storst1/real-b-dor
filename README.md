# REAL B’DOR · Сезон

Локальное приложение для коллекции сезонной статистики футболистов. Добавьте профиль Transfermarkt в конкретный сезон и получите таблицу матчей, голов, передач, оценок FotMob и исторической стоимости. Баллы за сезон складываются из взвешенной оценки отдельных матчей с поправкой на позицию и бонусов за результаты команды.

## Запуск

Нужен Python 3.13. В PowerShell из папки проекта выполните:

```powershell
.\run.ps1
```

При первом запуске скрипт создаст `.venv` и установит зависимости. Затем откройте приложение по адресу [http://127.0.0.1:8001](http://127.0.0.1:8001). Если виртуальное окружение уже существует, но зависимости ещё не установлены, выполните установку вручную:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m season_ledger
```

Другой порт можно задать командой `.\run.ps1 --port 8002`. Приложение работает локально; публикация и учётная запись не нужны. Для импорта нужен интернет. Запускайте один экземпляр приложения для одной базы.

## Как пользоваться

1. Выберите сезон в верхней строке или создайте новый. Доступны форматы «осень — весна» и календарный год.
2. Нажмите «Добавить игрока» и вставьте ссылку, например [профиль Harry Kane](https://www.transfermarkt.com/harry-kane/profil/spieler/132098). Игрок добавляется только в выбранный сезон. Тот же профиль можно отдельно добавить в другой сезон.
3. Дождитесь завершения импорта. В таблице есть порядковые номера, фото, флаги гражданств, эмблемы клубов и возраст на конец выбранного сезона (для текущего — на сегодняшнюю дату). Доступны поиск, фильтр позиции и сортировка. Нажмите на игрока, чтобы увидеть разбивку по турнирам, источники, даты и предупреждения.

FotMob сопоставляется автоматически. Если профиль не найден однозначно, в карточке можно выбрать кандидата либо указать ID или ссылку FotMob вручную. Данные Transfermarkt сохраняются и без оценок FotMob. Из карточки можно обновить данные или удалить игрока только из текущего сезона.

Колонка «Баллы» расположена между игроком и лигой. Правила весов, базы и бонусов зафиксированы в [документе «Баллы за сезон»](docs/season-points.md). В карточке игрока доступны расшифровка баллов и список матчей с индивидуальными весами. Если для расчёта не хватает истории или контекста, причина показана вместо выдуманного итога.

## Источники и смысл показателей

- **Transfermarkt:** профиль, позиции, гражданства, клубы, матчи, голы, передачи, минуты, место в лиге или достигнутая стадия кубка, история рыночной стоимости. Используется тот же SDK, что в `football-games-watched-tool`: [`transfermarkt-api==5.0.0`](https://github.com/felipeall/transfermarkt-api/tree/v5.0.0).
- **FotMob:** опубликованные оценки за отдельные матчи. Средняя оценка по турниру и сезону рассчитывается по доступным матчам с оценкой; размер выборки показан в карточке. Она может немного отличаться от сезонной карточки FotMob из-за округления исходных оценок. Это средняя оценка источника, а не собственный итоговый рейтинг приложения.
- **С поправкой на позицию:** оценка FotMob делится на коэффициент основной позиции игрока. Коэффициенты заданы относительно ST/SS: GK — 0,9253; CB — 0,9664; LB/RB — 0,9811; DM/CM — 1,0021; AM — 1,0158; LM/RM/LW/RW — 1,0096; ST/SS — 1,0000. Позиция CF из Transfermarkt относится к ST/SS. В таблице показаны скорректированные оценки; в карточке видны исходные значения FotMob и применённый коэффициент.
- В основной таблице числовая статистика берётся из Transfermarkt. Оценки FotMob присоединяются к однозначно сопоставленным турнирам и командам. Различия источников и неполное покрытие отражаются в предупреждениях.
- Для веса конкретного матча при достаточных данных используется FotMob напрямую. Сверка игры с Transfermarkt нужна только для недостающего контекста, например стадии плей-офф. Суперкубки исключены из колонки «Кубки» и кубковых бонусов; их матчи сохраняются в общем итоге и взвешенной оценке.
- В группе **«Лига чемпионов»** учитывается только основной турнир Лиги чемпионов УЕФА (Transfermarkt `CL`). Другие международные клубные турниры, включая Лигу Европы, Лигу конференций, Суперкубок УЕФА, клубный ЧМ и квалификацию ЛЧ, остаются в подробной карточке и входят в **«Всего за сезон»**, включая среднюю оценку и поправку на позицию; отдельной группы в основной таблице для них нет.
- Для завершённого финала поле «Место / стадия» показывает **1** для победителя или **2** для финалиста по результату команды, включая дополнительное время и пенальти. Если источник не позволяет надёжно определить исход, остаётся «Финал».
- **«—»** означает отсутствие данных; **0** — известный нулевой показатель или отсутствие выступлений в категории. Приложение не подставляет вымышленные значения и не содержит демонстрационных игроков.

Доступность и историческое покрытие источников могут различаться. При ограничении запросов приложение показывает ошибку или время ожидания; повторить загрузку можно позже.

Поправка рассчитывается из сохранённых исходных оценок без повторного импорта и без промежуточного округления средних. Для всех турниров сезона используется основная позиция из сохранённого профиля, а не позиция в каждом отдельном матче. Оценка каждого матча после деления на коэффициент ограничивается десятью **до** усреднения. Если для позиции нет коэффициента, скорректированная оценка отсутствует. Исходные данные FotMob сохраняются без изменений.

## Границы сезона

| Формат | Какие матчи учитываются |
| --- | --- |
| Клубы, «осень — весна» | Фактический сезон турнира по `seasonId` Transfermarkt. Перенесённые матчи, включая завершённые летом сезоны периода COVID, остаются в своём сезоне. Даты матчей используются и при сопоставлении с FotMob. |
| Сборные, обычные матчи | С 1 июля года начала по 30 июня следующего года. |
| Сборные, финальные турниры | С 1 сентября года начала по 31 августа следующего, по фактическим датам матчей. Летний турнир следующего года включается целиком и не переносится в соседний сезон. Перенесённые зимние турниры не теряются из-за старого года розыгрыша: Кубок Азии в январе 2024-го относится к 2023/24. |
| Сборные, Олимпиада | То же окно с 1 сентября по 31 августа. Олимпиада сохраняется в «Других турнирах» и общем итоге, без бонусов ЧМ / Евро / Копа. Обычные матчи молодёжных сборных не получают это расширение границ. |
| Календарный год | С 1 января по 31 декабря выбранного года. |

**Стоимость на конец сезона** — последняя датированная оценка Transfermarkt не позднее 30 июня для формата «осень — весна» или 31 декабря для календарного года. Если сезон ещё не завершён, срез ограничивается датой загрузки. Будущие оценки не используются. В карточке отдельно показаны дата самой оценки и дата среза; это позволяет видеть, насколько давней была последняя известная стоимость.

## Хранение и восстановление

SQLite-база создаётся автоматически в `data/seasons.sqlite3` относительно папки запуска. В ней сохраняются сезоны, игроки, исходные данные источников и очередь импорта. После перезапуска незавершённая очередь возобновляется. При неудачном обновлении ранее сохранённая карточка остаётся доступной; если не обновился только FotMob, сохраняются его последние успешно загруженные оценки с предупреждением.

При чтении карточки сопоставление турниров заново строится из сохранённых данных источников. Поэтому исправления категорий и сопоставления возвращают ранее пропущенные оценки без повторной загрузки; исходные ответы и время последнего импорта не меняются. Если опубликованные оценки источника остаются несопоставленными, окончательный рейтинг не рассчитывается по неполной выборке.

Для резервной копии остановите приложение и скопируйте файл базы. Сохранённые данные доступны без повторной загрузки источников. Другой путь базы задаётся перед запуском:

```powershell
$env:SEASON_LEDGER_DB = 'D:\Football\seasons.sqlite3'
.\run.ps1
```

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m pytest
```

Тесты проверяют разбор источников, границы сезонов и исторической стоимости, сопоставление и усреднение оценок, импорт, изоляцию сезонов и восстановление сохранённых данных.
